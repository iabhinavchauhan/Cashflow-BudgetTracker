# 💰 Cash Flow Budget Tracker

A simple, modern, and responsive **Cash Flow Budget Tracker** that helps users manage their income, track expenses, monitor their remaining balance, and generate a downloadable PDF report.

🔗 **Live Demo:** https://cashflowbudgettracker.netlify.app/

---

## 📌 About The Project

**Cash Flow Budget Tracker** is a lightweight personal finance management web application designed to make daily budgeting simple and easy.

Users can enter their total salary/income, add multiple expenses with their respective amounts, and instantly track how much money is remaining.

The application also provides a **Budget Low warning** when the remaining balance falls below a certain percentage of the available budget.

It also includes a **PDF report download** feature so users can save or share their budget information.

---

- 💰 Enter total salary/income
